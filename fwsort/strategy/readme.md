# btc-updown-15m 信号提示词

用 moa 模式，对 polymarkert 上 BTC 15分钟的涨跌，剩余时间超过3分钟的最近一个标的进行判断；下单信号以三个智能体中出现两个判断涨跌方向一致的信号为准。

## 输出要求
两种样式：   1、简洁版 2、详细版。
1、简洁版：{"标的代码": "btc-updown-15m-1785906900", "下单方向": "UP", "时间范围": "2026-08-05 13:45~2026-08-05 14:00"}
2、详细版（默认）：见下方

    输出 JSON 格式，
        成功：包含 标的代码、下单方向、时间范围、各模型分析结果、其它扩展信息。
        失败：success 为 False。，code 为非0，msg 为错误信息。
    
    ## JSON 结构样例
    
    ```json
    {
        "success": true,
        "code": 0,
        "msg": {
            "各模型分析结果": {
                "deepseek": "涨",
                "kimi-k2.6": "平",
                "minimax-m3": "涨"
            },
            "时间范围": "2026-08-05 13:45~2026-08-05 14:00",
            "其它扩展信息": ""
        },
        "标的代码": "btc-updown-15m-1785906900",
        "下单方向": "UP"
    }
    ```
    
    ## 字段说明与值可选
    
    | 字段 | 说明                                                                                                                                                                                                                                          |
    |------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
    | success | `True` \| `False`                                                                                                                                                                                                                           |
    | code | `0~n`，`0` 一般表示成功，与 `success: True` 同步                                                                                                                                                                                                       |
    | msg | 信息说明，可以增加描述信息方便人工查看，如：[各模型分析结果]、[时间范围（如2026-08-05 13:45~2026-08-05 14:00）]、[其它扩展信息]等                                                                                                                                                        |
    | 标的代码 | `btc-updown-15m-[动态最近15分钟时间值]`，其中 动态最近15分钟时间值 = `str(((int(time.time()) // 周期)) * (周期))`，周期 = `15 * 60`   就是 `https://polymarket.com/zh/event/btc-updown-15m-1785906900` 最后斜线后面的值 `btc-updown-15m-1785906900`，其中 `1785906900` 是本次分析的动态时间值   |    
    | 下单方向 | `UP` \| `DOWN`                                                                                                                                                                                                                              |
    
    ## msg 结构
    
    ```json
    {
        "各模型分析结果": {
            "deepseek": "跌",
            "kimi-k2.6": "平",
            "minimax-m3": "跌"
        },
        "时间范围": "2026-08-05 13:45~2026-08-05 14:00",
        "其它扩展信息": ""
    }
    ```
