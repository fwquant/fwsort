## 五、阶段 D6 · 🆕 新增需求（用户追加）

**目标**：填补报告里点出但没纳入 v1.0 计划的 3 个高价值缺口。

### D6-1 ｜ S-5 密码复杂度策略（zxcvbn）
- **改动点**：
  - `requirements.txt`：加 `zxcvbn>=4.4.0`
  - `fwsort/security/password.py`：新增 `evaluate_password(password: str) -> {"score": 0-4, "warning": str, "suggestions": [str]}`，score < 2 拒绝
  - `auth_router.py`：`register / change_password` 入口先调用 `evaluate_password`，score < 2 返回 400 + 提示
  - 前端 `web/templates/login.html` + `web/static/js/accounts.js`：注册/改密表单加实时强度条（5 段颜色：红/橙/黄/浅绿/深绿）
- **验收**：
  - `12345678` → 拒绝；`Password!2026abc` → 通过；
  - 前端实时反馈延迟 < 50ms；
  - pytest：`test_s5_weak_password_rejected` + `test_s5_strong_password_accepted`。

### D6-2 ｜ F-6 执行账户详情页增强
- **改动点**：
  - `web/templates/detail.html`：
    - 顶部增加净值曲线（mini ECharts，30 天）
    - 下方增加订单流水表（来自 `OrderExecutionLog`，按时间倒序分页）
    - 跟单贡献卡片：本账户被订阅的 FollowOrder 数量 + 总 PnL + 分成总额
  - `router/detail_router.py`（新建）：`GET /api/execution/{uid}/orders?page=1&page_size=20`、`GET /api/execution/{uid}/nav?days=30`
  - 前端 `web/static/js/detail.js`：请求/渲染两个新接口
- **验收**：
  - 详情页能直接看到该账户的订单表 + 净值曲线 + 跟单贡献；
  - 移动端自适应（订单表用卡片视图）。

### D6-3 ｜ F-7 智能体租用真实扣费
- **改动点**：
  - `fwsort/models.py`：新增 `user_balance` 表（user_id PK / balance_usd / frozen_usd / updated_at）
  - `fwsort/migrations.py`：`_NEW_TABLES_DDL` 追加 `user_balance` 表 DDL
  - `rental_router.py`：
    - `rental_quote`：先检查余额，不足返回 402
    - `rental_consume`：在事务里 `balance_usd -= price`，写 `rental_billing` 流水（user_id / agent_id / amount / created_at / status）
  - `router/admin_router.py`：`/admin/seed-balance?user_id=...&amount=1000` 给用户加余额（演示用）
  - 前端 `web/templates/rental.html` + `web/static/js/rental.js`：调用时若 402 显示"余额不足，请联系管理员充值"
- **验收**：
  - 演示模式：seed 余额 1000 USDT → 调用 5 USDT 智能体 → 余额剩 995；
  - pytest：`test_f7_rental_deducts_balance` + `test_f7_insufficient_balance_rejected`；
  - 真实扣费记录可在 `rental_billing` 表查询。
