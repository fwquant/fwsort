## 二、验证流程

### 2.1 启动服务

```bash
# 进入项目目录
cd D:\git\github\fwquant\fwsort

# 安装依赖
pip install -r requirements.txt

# 启动FastAPI服务
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### 2.2 验证步骤

#### 步骤1：创建用户

**接口**：`POST /api/auth/register`

**请求**：
```json
{
  "email": "test@example.com",
  "password": "Test@123",
  "nickname": "测试用户"
}
```

**预期结果**：返回用户ID和成功状态

#### 步骤2：登录获取Token

**接口**：`POST /api/auth/login`

**请求**：
```json
{
  "email": "test@example.com",
  "password": "Test@123"
}
```

**预期结果**：返回access_token

#### 步骤3：创建执行账户

**接口**：`POST /api/agent/accounts`

**请求**：
```json
{
  "name": "测试执行账户",
  "platform": "polymarket",
  "initial_balance": 1000.0
}
```

**Headers**：`Authorization: Bearer <access_token>`

**预期结果**：返回账户ID和UID

#### 步骤4：触发预测+投票+下单

**接口**：`POST /api/agent/predict-and-vote`

**请求**：
```json
{
  "symbol": "BTCUSDT",
  "timeframe": "15m"
}
```

**参数**：`account_id=<账户ID>`

**预期结果**：
- 3个智能体预测结果
- 投票决策结果
- 订单执行结果

#### 步骤5：查看榜单

**接口**：`GET /api/ranking/list`

**参数**：`rank_type=realtime`

**预期结果**：返回榜单列表（含Mock数据）

#### 步骤6：查看策略详情

**接口**：`GET /api/ranking/detail/{uid}`

**预期结果**：返回策略详细信息和历史排名

#### 步骤7：订阅跟单

**接口**：`POST /api/follow/subscribe`

**请求**：
```json
{
  "leader_uid": "<策略UID>",
  "mode": 3,
  "follow_amount_usd": 50.0
}
```

**预期结果**：创建订阅成功

#### 步骤8：查看可租用智能体

**接口**：`GET /api/rental/agents`

**预期结果**：返回可租用智能体列表
