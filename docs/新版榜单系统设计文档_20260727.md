## 一、需求背景与目标

### 1.1 当前系统分析（V1.0）

**现有架构**：
- 榜单主体：执行账户（ExecutionAccount）
- 排名依据：执行账户的综合绩效分
- 数据结构：用户 → 多个执行账户 → 各自独立排榜
- 问题：缺乏用户层面的聚合视图，无法直观展示用户整体实力

**现有数据模型**：
```
User (用户表)
  └── ExecutionAccount (执行账户表，榜单主体)
      └── StrategyPerformance (策略绩效表)
      └── OrderExecutionLog (订单执行日志)
      └── VoteDecision (投票决策)
      └── AgentPrediction (智能体预测)
```

### 1.2 新需求分析

**用户提出的新需求**：
1. **公共榜单**：按用户总成绩进行排序（用户层面的聚合榜单）
2. **私人榜单**：包含多个策略、多个智能体的反馈结果（策略层面）
3. **跟单系统**：根据仓位以及整个进行跟单（智能体/策略层面）

**核心变化**：
- 榜单主体从"执行账户"升级为"用户"和"策略"两个维度
- 引入多层级榜单体系：公共榜单（用户） + 私人榜单（策略）
- 跟单系统需要支持多层级：跟用户 / 跟策略 / 跟智能体

## 二、系统架构设计（V2.0）

### 2.1 榜单体系设计

#### 2.1.1 三级榜单体系

```
第一级：公共榜单（用户级别）
├── 全用户总榜（实时/日/周/月/总）
├── 平台分类榜（Polymarket/OKX）
└── 段位分类榜（钻石/铂金/黄金/白银/青铜）

第二级：私人榜单（策略级别）
├── 用户策略榜（该用户所有策略）
├── 平台策略榜（同平台策略）
└── 智能体策略榜（同类智能体）

第三级：智能体榜单（智能体级别）
├── 单智能体绩效榜（GPT-4o/Claude/Gemini）
├── 智能体组合榜（多智能体协作）
└── 租用智能体榜（可租用智能体）
```

#### 2.1.2 榜单主体定义

**公共榜单（用户榜单）**：
- **榜单主体**：用户（User）
- **排名依据**：用户所有执行账户的综合绩效（加权平均）
- **数据来源**：聚合用户下所有 ExecutionAccount 的绩效数据
- **计算公式**：
  ```
  用户综合分 = Σ(账户i的综合分 × 账户权重i) / Σ账户权重i
  账户权重 = 账户余额 / 用户总余额
  ```

**私人榜单（策略榜单）**：
- **榜单主体**：执行账户（ExecutionAccount）+ 策略组合
- **排名依据**：策略的综合绩效分（现有逻辑）
- **数据来源**：ExecutionAccount + StrategyPerformance
- **新增概念**：策略组合（Portfolio）
  - 一个用户可以创建多个策略组合
  - 每个策略组合包含多个执行账户
  - 策略组合有自己的综合绩效

**智能体榜单**：
- **榜单主体**：智能体组合（AgentPortfolio）或单智能体
- **排名依据**：智能体的预测准确率、盈利率、执行质量
- **数据来源**：AgentPrediction + VoteDecision + OrderExecutionLog
- **新增概念**：智能体绩效评估
  - 单智能体绩效：预测准确率、盈利率、响应时间
  - 组合绩效：MoA聚合效果、投票质量

### 2.3 榜单计算引擎

#### 2.3.1 用户综合分计算

```python
def calculate_user_composite_score(user_id: int) -> float:
    """计算用户综合分（公共榜单）"""
    # 1. 获取用户所有执行账户
    accounts = get_user_accounts(user_id)

    # 2. 计算权重（按余额）
    total_balance = sum(acc.current_balance for acc in accounts)

    # 3. 加权平均计算
    weighted_score = 0.0
    for acc in accounts:
        weight = acc.current_balance / total_balance if total_balance > 0 else 0
        weighted_score += acc.composite_score * weight

    # 4. 更新用户绩效聚合表
    update_user_performance_aggregation(user_id, weighted_score)

    return weighted_score
```

#### 2.3.2 策略组合综合分计算

```python
def calculate_portfolio_composite_score(portfolio_id: int) -> float:
    """计算策略组合综合分（私人榜单）"""
    # 1. 获取组合包含的所有执行账户
    portfolio = get_portfolio(portfolio_id)
    account_ids = json.loads(portfolio.account_ids)

    # 2. 聚合计算（可以按资产权重或均权）
    scores = []
    for acc_id in account_ids:
        acc_perf = get_account_performance(acc_id)
        scores.append(acc_perf.composite_score)

    # 3. 计算平均分
    portfolio_score = sum(scores) / len(scores) if scores else 0.0

    # 4. 更新策略组合表
    update_portfolio_performance(portfolio_id, portfolio_score)

    return portfolio_score
```

#### 2.3.3 智能体综合分计算

```python
def calculate_agent_composite_score(agent_name: str) -> float:
    """计算智能体综合分（智能体榜单）"""
    # 1. 获取智能体所有预测
    predictions = get_agent_predictions(agent_name)

    # 2. 计算预测准确率
    correct = sum(1 for p in predictions if p.is_correct)
    accuracy = correct / len(predictions) if predictions else 0.0

    # 3. 计算盈利率（参与投票的盈亏）
    votes = get_agent_votes(agent_name)
    winning_votes = sum(1 for v in votes if v.pnl > 0)
    win_rate = winning_votes / len(votes) if votes else 0.0

    # 4. 综合分计算（准确率40% + 盈利率40% + 执行质量20%）
    agent_score = (
        0.4 * accuracy +
        0.4 * win_rate +
        0.2 * get_execution_quality(agent_name)
    )

    # 5. 更新智能体绩效表
    update_agent_performance(agent_name, agent_score)

    return agent_score
```

async def execute_follow_order(subscription_id: int):
    """执行跟单订单（V2.0 多层级）"""
    subscription = await get_subscription(subscription_id)

    if subscription.follow_level == 1:
        # 跟用户：获取用户所有账户的最新订单
        leader_accounts = await get_user_accounts(subscription.target_id)
        recent_orders = await get_recent_orders(leader_accounts)

    elif subscription.follow_level == 2:
        # 跟策略组合：获取组合内所有账户的最新订单
        portfolio = await get_portfolio(subscription.target_id)
        account_ids = json.loads(portfolio.account_ids)
        recent_orders = await get_recent_orders(account_ids)

    elif subscription.follow_level == 3:
        # 跟智能体：获取该智能体的最新投票决策
        recent_votes = await get_agent_recent_votes(subscription.target_id)
        recent_orders = await convert_votes_to_orders(recent_votes)

    # 执行跟单订单
    for order in recent_orders:
        await execute_copy_order(subscription, order)

## 五、技术要点与注意事项

### 5.1 性能优化

**榜单计算优化**：
- 用户综合分：每小时更新一次（Celery定时任务）
- 策略组合分：实时计算（账户变更时触发）
- 智能体绩效：每日凌晨更新

**缓存策略**：
- 公共榜单：Redis缓存，有效期1小时
- 私人榜单：Redis缓存，有效期30分钟
- 智能体榜单：Redis缓存，有效期24小时

### 5.2 数据一致性

**事务处理**：
- 用户绩效聚合：使用数据库事务保证一致性
- 策略组合更新：乐观锁机制，避免并发冲突
- 跟单执行：分布式锁，避免重复跟单

### 5.3 权限控制

**榜单可见性**：
- 公共榜单：所有用户可见，只能看到公开信息
- 私人榜单：
  - 用户自己的策略组合：完全可见
  - 公开的策略组合：其他用户可见（不含敏感信息）
- 智能体榜单：所有用户可见

### 5.4 风控升级

**多层级风控**：
- 用户级：总资产日亏损上限30%
- 策略组合级：单组合日亏损上限20%
- 账户级：单账户日亏损上限20%（现有）
- 智能体级：预测失败次数过多自动降级
